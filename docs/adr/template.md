# NNNN. タイトル

- Status: Proposed
- Date: YYYY-MM-DD

## Context

この決定が必要になった背景・課題・制約を書く。何が問題で、何を決める必要があったか。

## Decision

決定内容を書く。1 つの決定に絞り、断定形（「〜する」）で書く。

## Consequences

この決定によって生じる結果を書く。良い影響・悪影響・将来の制約・フォローアップ事項を含める。

## Alternatives considered

検討した代替案と、採用しなかった理由を書く。原典に記録がない場合は、その旨を書く（推測で書かない）。
