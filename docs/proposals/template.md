# 企画: タイトル

- Status: Exploring
- Date: YYYY-MM-DD
- 決着時の反映先: ADR / 要件文書（Concluded・Dropped 時に記入）

## Problem

解決策の不在ではなく、具体的なストーリーで書く。誰が・いつ・何に困っているか。現状の回避策があれば書く。

## Solution

提案する姿を書く。粗くてよい（詳細は決着時に ADR で詰める）。

## Appetite

この企画に使う時間の上限（任意）。だらだらと探索を続けないための制約。

## Rabbit holes

罠（魅力的に見えるが時間を溶かす論点）と、先回りして決めた対処を書く。

## No-gos

意図的にやらないこと。期待されそうだが今回のスコープから外すものを明示する。

## 未解決の問い

決着までに解く必要がある問いを列挙する。

## 決着

Concluded / Dropped になったときに書く。決定は ADR に、要件の変化は要件文書に反映したうえで、この文書を削除する。却下の場合は理由をここに残す。
