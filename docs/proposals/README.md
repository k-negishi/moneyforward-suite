# 企画の記録（proposals）

このディレクトリは、決定前の企画・探索の文書を置く場所である。決定は [ADR](../adr/README.md) に、決定を経た要件は [要件文書](../requirements.md) にある。

## proposals とは

- 決定前の探索（Problem・Solution・スコープ案・Rabbit holes・No-gos・未解決の問い）を 1 企画 1 ファイルで記録する。
- 決着したら、決定は ADR に、要件の変化は要件文書に蒸留し、この文書は削除する（経緯は git 履歴に残る）。
- 探索中は書き換えてよい（生きている文書）。承認後は書き換えない ADR とは性質が異なる。

## 運用規約

| 項目 | 規約 |
|---|---|
| 書式 | `template.md`（Shape Up の pitch の圧縮版） |
| Status | `Exploring` / `Concluded` / `Dropped` の 3 種 |
| ファイル名 | `<slug>.md`（内容を表す英小文字の kebab-case） |
| 使いどころ | 複数の決定に分かれる・調査を伴う・複数セッションにまたがる企画。単発の決定は会話で詰めて ADR だけを書く（ADR の Context が経緯を兼ねる） |
| 決着時 | 決定を ADR に、要件の変化を要件文書に書いてから、この文書を削除する。Dropped も理由を残す |
| 禁止 | 実データ・Secret・金融情報を書かない（Public リポジトリのため） |

## 決定との関係

「探索は未来形、決定は過去形」を原則とする。proposals は「〜すべき」を議論し、ADR は「〜と決めた」を記録する。決着した企画の決定を探すときは [ADR の決定一覧](../adr/README.md) を見る。
